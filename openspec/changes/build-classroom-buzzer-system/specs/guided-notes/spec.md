# Spec Delta

## Purpose

讓老師以 Google Sheets Guided Notes 作為題目來源，依每份講義的實際標記動態建立題目與填空格對應，並安全寫回搶答成功答案。

## ADDED Requirements

### Requirement: 動態匯入講義
系統 SHALL 讓老師指定有權存取的 Google Sheets 講義，依支援的明確題目標記動態辨識題號及其答案儲存格，建立與講義一致的題數，無須匯入題目敘述，且不得寫死題數或座標。

#### Scenario: 不同講義與位置
- **WHEN** 老師匯入兩份各有不同題數或標記位置且符合文件化格式的講義
- **THEN** 各次匯入均顯示對應題號與題數，並記錄該次實際位置

#### Scenario: 無效標記
- **WHEN** 講義沒有可辨識題目、題號重複或答案格無法唯一識別
- **THEN** 系統拒絕匯入並說明原因，不使用部分結果開始活動

### Requirement: 寫回原講義
系統 SHALL 讓老師於活動結束後將各題第一順位答案寫入該次匯入的原試算表對應答案格，不寫入未作答題目且不覆蓋其他儲存格內容。

#### Scenario: 混合作答與未作答
- **WHEN** 老師匯出包含已作答及未作答題目的活動
- **THEN** 僅已作答題的對應答案格被寫入成功答案，未作答格與其他內容保持原狀

#### Scenario: 講義結構改變
- **WHEN** 匯入後答案格標記已移動或變更，老師嘗試匯出
- **THEN** 系統拒絕寫入並提示重新匯入或處理衝突，不寫入錯誤位置

### Requirement: 存取與匯出失敗回報
系統 SHALL 在授權不足、無法讀取或寫入試算表時回報失敗，不宣稱操作成功。

#### Scenario: 沒有寫入權限
- **WHEN** 老師匯出至無編輯權限的試算表
- **THEN** 系統顯示匯出失敗及可理解的原因

### Requirement: 保護機敏資訊
系統 SHALL 使用版本庫外提供的憑證，且不得將密碼、憑證或 API 金鑰納入版本庫。

#### Scenario: 設定授權
- **WHEN** 使用者依文件設定 Google Sheets 存取
- **THEN** 憑證由本機外部設定提供而不需提交至版本庫
